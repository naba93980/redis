## Redis

A nodejs-redis app and collection of notes covering Redis data structures and its usage with Node.js.

### Topics Covered

- **Strings** — Redis string commands and operations
- **Hashes** — working with hash data structures
- **Lists** — list operations and commands
- **Sets and Sorted Sets** — set operations and sorted collections
- **Pub/Sub** — publish-subscribe messaging
- **Streams** — Redis Streams fundamentals
- **General Commands** — commonly used Redis commands
- **Node.js Integration** — connecting and interacting with Redis from a Node.js application



### Getting Started

**Prerequisites:** Redis, Node.js, and npm.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/redis.git
   cd redis
   ```

2. Start a Redis server locally at port 6379.

3. Navigate to the Node.js example:

   ```bash
   cd redis-nodejs
   npm install
   ```

4. Run the application using the script in `package.json`, or execute:

   ```bash
   node app.js
   ```


### Purpose

A learning reference for understanding Redis data structures, commands, and integration with Node.js.
